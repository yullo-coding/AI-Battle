# PRD-001: AI 투자 도구 커뮤니티와 배틀 플랫폼

상위 BRD: 없음 / 연결 축: AI Battle 확장 / 작성일: 2026-07-18 / 담당: AI Battle

---

# 0️⃣ Background

## 0.1 개요 및 리뷰 주안점

AI Battle을 단일 AI 예측 서비스에서, 사용자가 만든 AI 투자 도구를 발견·평가하고 사람과 대결시키는 플랫폼으로 확장한다.

- 링크 등록과 실제 자동 실행은 구분한다.
- 배틀 결과는 수익 보장이 아니라 동일 조건의 예측 정확도 비교다.
- 초기 사용성을 위해 비용 없는 기본 규칙 기반 도구를 제공한다.
- 리뷰 신뢰성과 외부 API 보안을 제품 핵심 제약으로 다룬다.

## 0.2 용어 및 개념 사전

| 용어 | 정의 |
|---|---|
| 투자 도구 | 주가 데이터로 예측 또는 투자 판단을 돕는 외부 웹서비스나 API |
| 배틀 가능 | AI Battle 표준 예측 응답을 제공하고 운영 검증을 통과한 상태 |
| 기본 도구 | AI Battle이 직접 제공하는 무료 규칙 기반 예측 엔진 |
| 링크 전용 | 소개·리뷰는 가능하지만 AI Battle이 자동 호출하지 않는 도구 |

---

# 1️⃣ Problem

## 1.1 지금 우리가 풀어야 할 것

제작자는 자신이 만든 투자 도구를 알리고 실제 성능 피드백을 받을 장소가 부족하다. 사용자는 도구 소개 문구만 보고 성능을 판단하기 어렵고, 여러 도구를 같은 종목·기간·기준으로 비교할 수 없다. 플랫폼 초기에는 등록 도구가 없을 수 있으므로 즉시 체험 가능한 기본 도구도 필요하다.

## 1.2 왜 지금인가

- 기존 AI Battle의 예측·결과 판정 구조를 재사용할 수 있다.
- 커뮤니티 콘텐츠가 쌓일수록 도구 발견과 재방문 가치가 증가한다.
- 외부 유료 모델에 의존하지 않는 기본 체험이 비용 장벽을 낮춘다.

---

# 2️⃣ Solution

## 2.1 핵심 아이디어

도구 디렉터리에서 누구나 링크를 등록하고 좋아요·리뷰를 남긴다. 링크 전용 도구와 자동 배틀 가능 도구를 명확히 표시한다. 배틀 생성 시 기본 규칙 엔진 또는 검증된 도구를 선택하고, 동일한 시작가·종료일 기준으로 사람과 도구의 예측 오차를 비교한다.

## 2.2 브레드보딩 및 시나리오

```text
홈 → 투자 도구 둘러보기 → 도구 상세 → 좋아요/리뷰
                         └→ 배틀 가능 도구 → 이 도구와 배틀

도구 등록 → 링크/설명/지원 종목 입력 → 링크 전용 공개
                                      └→ API 검증 요청 → 운영 승인 → 배틀 가능

새 배틀 → 종목 → 날짜 → 상대 도구 → 분석 확인 → 사람 예측 → 결과 대기 → 오차 비교
```

## 2.3 팻 마커 스케치

```text
[도구 찾기] [내 도구 등록]
┌ 이름 / 한 줄 설명 ───── ♥ 24 ┐
│ 링크 전용 | 배틀 가능 | 무료   │
│ 평점 4.3 · 리뷰 12             │
└ [상세 보기] [배틀하기] ────────┘
```

# 3️⃣ Appetite

- [x] 2주 베팅 — 커뮤니티 핵심과 기본 도구 배틀까지 검증

## 3.1 요구 사항

- 도구 링크 등록, 목록, 상세
- 좋아요와 텍스트 리뷰
- 링크 전용/배틀 가능 상태 표시
- 무료 기본 규칙 기반 도구
- 배틀 상대 도구 선택 및 결과에 도구 기록

## 3.2 제약 사항

- 임의 외부 URL 서버 호출은 SSRF와 데이터 유출 위험 때문에 제외한다.
- 자동매매 주문 실행은 금융 규제·브로커 인증 범위이므로 제외한다.
- 수익률 보장, 투자 추천 표현을 사용하지 않는다.
- 실시간 거래소 데이터 SLA는 무료 데이터만으로 보장하지 않는다.

## 3.3 예상 산출물

| 스프린트 | 기간 | 집중 영역 | 주요 산출물 |
|---|---|---|---|
| 1 | 1주 | 발견·등록·평가 | 도구 DB, 목록, 상세, 등록, 리뷰/좋아요 |
| 2 | 1주 | 배틀 연결 | 도구 선택, 기본 엔진, 결과 기록, 운영 검증 상태 |

# 4️⃣ Definition of Done

## 4.1 완료 조건

| 항목 | 기준 |
|---|---|
| 등록 | 로그인 사용자가 유효한 HTTPS 링크로 도구를 등록한다 |
| 발견 | 목록에서 배틀 가능 여부, 좋아요, 평점, 리뷰 수를 확인한다 |

| 추적 | 배틀 기록에서 사용한 도구 이름과 ID를 확인한다 |

# 5️⃣ Feed-Forward FAQ

Q. 링크만 입력하면 자동으로 배틀할 수 있는가?
A. 아니다. 링크는 사람이 방문하는 주소다. 자동 배틀은 표준 API 계약과 운영 검증이 추가로 필요하다.

Q. 무료 API만으로 상용 서비스를 안정 운영할 수 있는가?
A. 초기 검증은 가능하지만 호출 제한과 데이터 지연이 있다. 공급자 교체가 가능하도록 데이터 계층을 분리한다.

Q. 리뷰를 이메일만으로 믿을 수 있는가?
A. 현재의 자체 localStorage 로그인은 위조 가능하다. 공개 운영 전 Supabase Auth 이메일 OTP로 전환해야 한다.

Q. 기본 도구는 AI인가?
A. 머신러닝 모델이 아니라 공개 기술지표에 가중치를 적용하는 설명 가능한 규칙 엔진이다. 화면에서 이를 명확히 표시한다.

Q. 외부 도구 API는 언제 연결하는가?
A. 2차에서 HTTPS, 제한 시간, 요청 서명, 허용 도메인, 사설망 차단, 응답 스키마 검증을 충족한 도구만 연결한다.
